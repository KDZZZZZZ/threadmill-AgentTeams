# 项目级 GUI Skills

本目录只服务于 Threadmill AgentTeams 的 GUI 设计与实现。

- `design-taste-frontend`、`baseline-ui`、`create-design-md`、`fixing-accessibility`、`better-icons` 由 `skills` CLI 以复制模式安装，来源记录在根目录 `skills-lock.json`。
- `design` 是项目内的 `DESIGN.md` 工作流副本。
- `impeccable` 为受限安装：仅保留已审查的核心说明和本项目实际使用的参考文档，不包含脚本、Hooks、浏览器控制或生成代理。
- `motion` 为受限安装：仅保留已审查的 Markdown 指导，不注册 Motion 或 Motion+ 远程 MCP。
- Google `@google/design.md` CLI 作为根项目开发依赖安装，用于 lint 和 export 校验。

这些限制让技能只影响设计决策和本地文档校验，不获得额外的浏览器、凭据或远程执行权限。
