# ADR 0002: PostgreSQL Outbox and MinIO Artifact Storage

Status: Accepted

Date: 2026-08-10

## Context

The MVP must provide revision CAS, exactly one effective phase lease, auditable graph mutations, replayable UI events, and durable artifacts without introducing Kafka, Redis, or a second event bus.

Authoritative sources:

- `docs/plans/2026-08-10-threadmill-repository-implementation.md` §3
- `docs/event-artifact-store.md`
- `docs/coordination-graph.md` §1, §4
- `docs/threadmill-unified-design.md` §5.7

## Decision

Threadmill uses one PostgreSQL database for transactional state. Modules own separate tables, but critical mutations commit domain state, audit event rows, and outbox rows in the same transaction.

PostgreSQL stores:

- Coordination Graph tasks, endpoints, edges, blockers, results, revisions, commands, and leases.
- Context Graph nodes, edges, subgraph membership, recipient bindings, projections, subscriptions, candidate buffers, and review records.
- Event Log entries, consumer cursors, outbox records, idempotency keys, and capacity revision.
- Invocation, decision, and manager input references needed for recovery.

MinIO/S3 stores large objects. PostgreSQL stores only object metadata: stable artifact ID, object key, SHA-256, media type, size, ACL, source event/invocation, retention class, and created timestamp.

Message dispatch uses PostgreSQL outbox with cursor polling and database notification where available. Event cursors are generated by Threadmill Event Log, not by filesync watermarks, Matrix timelines, or object-store modification times.

## Consequences

- A graph mutation without an audit event is impossible when the transaction commits successfully.
- Event replay and SSE resume use the same ordered Event Log cursor model.
- Large payloads never enter Event Log rows; cross-phase data moves by `ArtifactRef`.
- MinIO/FileSync is a physical transport and storage substrate, not an event-ordering authority.

## Rejected Options

- Kafka, Redis Streams, or another broker for MVP dispatch.
- Storing transcripts, diffs, screenshots, or test logs directly in Event Log payloads.
- Treating AgentTeams Matrix messages or FileSync watermarks as Threadmill events.
